# Node 002c — ADMIN(?)

**Tree:** Sapling · **Parent:** [001 — Capability Inventory](../001-capability-inventory/node.md) · **Trunk:** undecided · **Status:** hot
**This file is a T0 leaf** (`002c-t0-b`, molt successor per SCRIPT-SPEC.md).
**Format:** 9:16 vertical · 60–90s · VO-driven

---

## State change (R1)

The world's category changes: it is not scenery, it is a **system** —
with objects, labels, and services — and his own label is corrupted in a
way nobody else's is. His identity becomes an open question with
evidence attached.

## Hook (R5)

The debug overlay tags him `ADMIN(?)` — half-corrupted, unlike every
clean label around him — and vanishes at dusk. The question a viewer can
state: *why is the tree labeled ADMIN, and what happens at the next
sunset?*

---

## Script

**COLD OPEN — 0:00–0:05**

Macro shot: a tiny two-leaf banyan sapling alone in a huge field,
straining — visibly, absurdly, its whole small body tensed.

> **VO (dry, tired, engineer):** Engineer, died, reincarnated as a tree. Capabilities: sense and grow. Day nine: I am testing for an undocumented third.

**THE TEST LOG — 0:05–0:40**

A rapid montage. Each experiment is one shot plus one line of a growing
on-screen log, deadpan.

He strains at nothing, hard.

```
TEST 12: think "menu" very hard............ null
```

He strains harder. A bird lands on him, unimpressed.

```
TEST 13: think "STATUS WINDOW" in caps..... null
TEST 14: think it in a cool anime voice.... null (bird acquired)
```

Timelapse: he grows two twigs at precise angles.

```
TEST 23: grow twigs at exactly 90°......... success. system response: none.
TEST 24: spell "HELLO" in root pattern..... success. readable only by moles.
TEST 25: mole response..................... ate the H
```

Night. Stars wheel overhead.

```
TEST 31: pray.............................. embarrassing. null.
TEST 32: threaten the sky.................. null. bird came back though.
```

> **VO:** Conclusion after nine days: this world has no interface, no console, no cheat menu. It's just… a world. Which would be fine. Except — reincarnation *happened*. Somebody implemented that. And nobody builds a feature that big without leaving a debug flag on somewhere.

**SUNSET — 0:40–1:00**

Golden hour. The light goes long and amber. The bird flies home.
Everything is soft, warm, cinematic — and then, for exactly three
seconds, the sun touches the horizon and the world *flickers*.

WIREFRAME. Everything at once: the grass is a lattice of green vectors,
the rocks are low-poly meshes, the distant hills are flat billboards,
the bird overhead is a rigged armature trailing a label. Floating tags
snap open over every object, clean monospace on the amber sky:

```
GRASS      v2.3.1-stable
ROCK       static · no owner
STREAM     service · flow=managed
BIRD       npc_ambient · loop=daily
```

> **VO (whisper):** …There it is. There's the debug layer. Render distance: everything. Refresh: sunset. *Somebody left the flag on.*

**THE LABEL / HOOK — 1:00–1:25**

Over his own thin trunk, a tag renders. It stutters — half the
characters corrupted, resolving and failing:

```
▓▓P▓IN(?)
A▓M▓N(?)
ADMIN(?)
```

> **VO:** That's… that's not `npc`.

The sun slips below the horizon. The wireframes collapse, the tags fold
shut, the world snaps back to soft ordinary dusk — grass, rocks, stream,
as if nothing happened. One small plant alone in an enormous dark field.

> **VO:** ADMIN. Question mark. *Whose* question mark — mine, or the system's?

SMASH TO BLACK.

```
TEST 33: wait.
```
