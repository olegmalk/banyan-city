# footage-archive — superseded takes, kept for provenance (R6)

Nothing here is published. `build_site.py` copies `takes/clips/`, not this
directory, and no leaf names any file in it.

**Why these moved (2026-08-01).** Fifteen takes of the 18-beat script were
animated on Kaggle with Stable Video Diffusion, which ships under Stability's
**non-commercial research** licence. The tree publishes CC BY 4.0 — a licence
that offers commercial reuse SVD forbids — so these takes can never be part of
an episode. They sat in the live assembly directory `clips/` until
`licence_gate.py` named them.

They are kept, not deleted: they are real evidence of what the Kaggle route
produced, and R6 says superseded work is archived rather than erased. Promoting
any of them back into a cut would re-break the gate, which is the point.
