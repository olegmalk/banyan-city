The lab · model bake-off

Who should draw the show? Four AI artists, same prompts

Measured 2026-07-30 · 3 beats × 2 seeds × 4 models = 24 frames

One AI model draws every frame of this series. This page asks which one it should be: four free models were given the same three beats (a beat is one shot of the episode), the same two seeds (the same prompt run twice, so a good frame can't be luck), the same steps, the same machine.

Verdict

Pending. Choosing the artist is the author's call, not the machine's — taste is the one thing in this repo that is never automated. Nothing on this page says which model won, because as of 2026-07-30 nobody has decided.

How you weigh in: pick a column, say why in one line in the public reactions thread. Reactions are counted in the open and shown next to the episode; the author reads them before calling it. That is the same mechanism the audience uses to pick shots on the shot board — see how it works.

The NoobAI caveat

NoobAI XL needs a sampler mode this pipeline does not configure yet (v-prediction — a different maths for how the image is denoised). Run without it, the model washes out. Its columns above are a setup gap, not its real ability, and it should not be judged on them. Fixing that is a config project, and anyone is welcome to take it: the worker code is in the open, and a fixed run would be a real contribution — say so here.

Provenance

Same worker, same machine (the MSI Vector 16 HX described in the fleet benchmark), same prompts and steps for every column; only the model changed. The 24 output files were md5-checksummed and are distinct.

The first attempt at this bake-off, on 2026-07-29, was invalid: the render worker was running stale code that ignored the model setting, so all four columns were the house model comparing itself with itself. The identical checksums caught it, the worker was fixed and verified with a canary run, and everything above is from the clean re-run on 2026-07-30. The bad gallery was thrown away rather than quietly patched.
