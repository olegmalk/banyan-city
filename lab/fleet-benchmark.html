The lab · fleet benchmark

The render farm, benchmarked

Measured 2026-07-29 · identical task on every machine

Every machine was given exactly the same job: two frames, 40 steps each, 832×1216, same model, same seeds, one fixed beat of episode 1 (beat 09 — a beat is one shot of the episode). Nothing here is a spec sheet; it is a stopwatch.

Why speed is the whole game

≈ 1 minute — how long the gaming laptop takes to render a full ballot round: four candidate versions of one shot, put to the audience so they can pick which one becomes canon. The same round takes about 12 minutes on the studio Mac. Faster machine, more votes, more of the show decided by the people watching it.

Two measured reasons the Macs are slower

These two differences are the ones this benchmark can actually attribute, and together they account for roughly 2× of the ~13× gap. The rest is raw throughput and memory bandwidth between a 2026 desktop-class GPU and a laptop system-on-chip — real, but not something this test isolated, so it is not claimed here as if it were measured.

 NVIDIA laptop GPUApple M-series
Dedicated AI silicon (tensor cores) yes — this maths is its home game no; a general-purpose GPU does the work
Numeric precision we can use half precision (fast) double the width — half precision renders black frames on these chips, so we pay for the safe path
So, per frame 1× work on specialised silicon 2× work on general silicon
Accounted for here — ≈ 2× of the ~13×; the remainder is unattributed silicon throughput

The fleet in one line

The Windows laptop renders, the Macs write and direct, the cloud waits for surges — so four beats can iterate in parallel. The same four names are used on every lab page: the renderer (MSI Vector 16 HX, RTX 5070 Ti 12 GB), the second Mac (M3 Pro, 36 GB), the studio Mac (M1 Pro, 32 GB), and the surge lane (rented RunPod RTX 4090).

What the money looks like

$1.24 is the total cash this project has spent, ever — $0.50 of rented cloud GPU (all of it on 2026-07-29, the day the cloud numbers above were measured) and $0.74 of paid video-API tests. Everything rendered on the household machines cost $0. That is one number with one source: it is the sum of all 73 rows of ledger/render-spend.csv, read 2026-07-30. Caps live in code — $8 per command, $20 lifetime (budget.yaml), $5 per evening on the cloud lane. Every render, vote and cent is public.
