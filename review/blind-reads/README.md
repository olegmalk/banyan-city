# Blind reads — the committed record

A blind read is an experiment. Like any experiment it is worth nothing unless
someone else can see what was shown, what the labels meant, and what the reader
actually said. **A measurement that is not committed did not happen.** The rule
and its reasoning are recorded in `taste/steward-model.ledger.yaml` under
`RULE-a-measurement-that-is-not-committed-did-not-happen-0815`.

Not to be confused with `taste/blindsets/`, which is a different instrument: those
score the *taste file* against the author's own blind picks (PRD §7.3). These
record blind reads of *rendered frames* by a reader with no project context.

## What every read here carries

1. **The frames the reader was shown** — either the files, or a sha256 plus a
   reproduction command verified to regenerate them byte-for-byte.
2. **The label mapping** — which blind code was which clip, and how it was drawn.
   A verdict whose mapping is lost is uninterpretable; do not guess it back.
3. **The verbatim verdict** — the reader's own words, not a summary of them.
4. **The prompt the reader was given**, because the question shapes the answer.
5. **The caveats the commissioning lane stated itself**, kept in the record even
   when they weaken the finding. Especially then.

## Why no PNGs are committed here

`.gitignore:60` ignores `review/**/*.png`, and that rule is repo policy. It costs
nothing here: every sheet in this directory was regenerated byte-identically from
a clip already in git plus a committed script, and the sha256 of each is recorded.
A hash plus a verified command is a better record than a binary blob — it proves
the artifact *and* the path back to it. If a future read cannot be reproduced from
committed inputs, that read must commit its frames (`git add -f`) instead.

## Standing consequence of the sparse/dense result

Any verdict of the form "the motion steps / stutters / lurches / drops frames"
that was reached from an evenly-spread contact sheet is **not evidence** and must
be re-read on consecutive frames before it is acted on. A sheet sampling every
6th frame cannot tell a genuine jump-cut from a fast movement. The tool that
produces consecutive strips is `pipeline/coldread_frames.py`; note the period
caveat recorded at `review/ep2-picks/done-definitions.yaml:coldread_period_caveat_0815`
before applying it to a clip that is not the 97-frame recipe.
